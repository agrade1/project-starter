# 대상 프로젝트 AGENTS.md에 병합할 조각

이 파일 자체는 자동 로딩 지침이 아니다. 아래 블록을 대상 루트 `AGENTS.md`에 병합한다. 기존 파일을 대체하지 않는다. `docs/project/PROJECT.md`는 정본이 다른 곳에 있으면 그 경로로 바꾼다.

```md
## 전문 역할 작업 지침

재사용 지침은 docs/agent-kit/에 있다. 작업을 시작할 때
`docs/agent-kit/common/START_HERE.md`와 `docs/agent-kit/common/WORKING_RULES.md`를 읽고
이번 작업의 역할·기능·워크플로만 선택한다. 모든 역할 문서를 한꺼번에 읽지 않는다.
프로젝트 요구사항과 현재 상태는 `docs/project/PROJECT.md` 또는 그 문서가 가리키는 기존 정본을 따른다.
정본이 없으면 기존 코드/문서부터 조사하고 필요한 경로표만 만든다.
사용자 변경과 기존 지침을 보존한다. 승인된 범위 안에서 검증·인계까지 진행한다.
미확인 사실·mock·실제 사용자 흐름·출시를 구분하고 독립 리뷰는 작성자와 다른 세션에서 수행한다.
```
