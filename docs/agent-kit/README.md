# Portable Agent Kit

1인 창업자가 필요한 전문 역할만 불러 실제 프로젝트를 끝내기 위한 한국어 작업 지침이다. 실행 엔진·에이전트 자동 호출·비용 차단 장치를 제공하지 않는다.

시작: [QUICKSTART](QUICKSTART.md) → [문서 선택](common/START_HERE.md) → 작업에 맞는 역할 하나.
새 프로젝트에는 이 폴더를 `docs/agent-kit/`으로 복사한다. 프로젝트 요구사항과 결과는 기존 문서 또는 `docs/project/`에 두며 킷과 분리한다.

| 영역 | 내용 |
|---|---|
| [공통](common/WORKING_RULES.md) | 승인 범위·근거·예산·파일 소유권·인계 |
| [하네스·루프·그래프](common/OPERATING_MODEL.md) | 상태·조건부 전이·비평 개선·중단과 재개 |
| [독립 비평 입력](templates/REVIEW_PACKET.md) | 문제로 기준을 세운 뒤 산출물 검토; 작성자 대화 제외 |
| [역할/기능 선택](common/START_HERE.md) | 8개 역할과 필요한 기능만 읽는 인덱스 |
| [워크플로](workflows/new-service.md) | 새 서비스, 기능 추가, 버그 수정, 기획·디자인 종료 |
| [프로젝트 양식](templates/PROJECT.md) | 기존 문서에 병합하거나 필요한 절만 사용 |
| [Orca](adapters/orca/README.md) | 기능 확인·프로젝트별 설정·세션 프롬프트 |
| [Codex](adapters/codex/README.md) / [Claude Code](adapters/claude-code/README.md) | 대상 프로젝트 진입 지침 |
| [작은 기능 예시](examples/favorite-filter.md) | 문서만으로 인계 흐름 따라가기 |
| [아이디어 접수 예시](examples/idea-to-first-task.md) | 원문 대응·첫 TASK·비평 수정·재개 연습 |

역할 8개가 세션 8개를 뜻하지 않는다. 작은 변경은 구현자 1명과 별도 리뷰어로 충분할 수 있다. 문서도 모두 만들지 않는다. 프로젝트 규칙이 우선하며 기존 파일과 사용자 변경을 보존한다.
