# 프로젝트 맥락 · 범위 · 결정

이 양식은 대상 프로젝트 문서에 필요한 절만 복사한다. 기존 파일이 있으면 해당 절을 갱신한다.

- 프로젝트/정본 문서 경로:
- 실제 작업 디렉터리 / 브랜치 / HEAD / 사용자 dirty 변경:
- 고객과 해결할 문제 / 현재 대안:
- 관측 근거 / 가정 / 미확인:
- 새 사업일 때: 사용자·구매자 / 가격 가설 / 첫 고객 채널·피드백 경로 / 운영 시간·비용:
- 제품 성과: 핵심 지표·관측 방법 / 목표의 근거·가정 / 판단 시점·유지/축소/중단 조건:
- 이번 작업 유형: 조사·기획 / 검증용 프로토타입 / 제품 개발 / 출시 준비
- 승인자·승인 내용·시각 / 제외 범위 / 외부 영향·비용 한도:
- MVP: 필수 사용자 흐름 / 제외 기능 / 기능별 우선순위와 이유:
- 수용 기준(행동 → 관측 결과) / 실패·중단 기준:
- 알려진 코드·문서 충돌 / 사람이 답할 질문:

아이디어/기획서 원본은 보존한다. 기존 PRD에 대응표가 있으면 링크만 남긴다. 원문 전체를 복제하지 않고 절·페이지를 지정한다. 원문에 있다는 이유만으로 구현 승인된 요구로 바꾸지 않는다.
